    Cara memakai

    Papan ketik: Tab untuk memilih objek. Tombol panah menggeser 0,25 m. R memutar 90°. Delete menghapus. Esc melepas pilihan.

    Sentuh: Ketuk objek untuk memilih. Seret objek untuk memindahkannya. Seret ruang kosong untuk memutar kamera, cubit untuk memperbesar.

    Kursor: Seret objek untuk memindahkannya. Seret ruang kosong untuk memutar kamera, gulir untuk memperbesar.

    Kembalikan denah awal?

    Semua perubahan Anda dihapus dan denah kembali ke contoh awal.

    Aplikasi denah untuk kedai atau toko Anda

    Kami bisa membuat aplikasi seperti ini dengan ukuran ruang dan perabot milik Anda. Aplikasi sederhana mulai Rp 3jt, pengerjaan 3–6 minggu. Fitur tambahan dihitung di penawaran tertulis.
