FAQ

Yang sering ditanyain

Berapa lama pengerjaannya?

Desain konten 1–3 hari, logo 3–7 hari, katalog 3–5 hari, website 1–4 minggu tergantung jumlah halaman. Butuh cepat? Ada layanan ekspres 1x24 jam dengan biaya tambahan 30%.

Revisinya berapa kali?

Sesuai paket yang dipilih. Revisi tambahan untuk desain mulai Rp 10rb, untuk web dan aplikasi dihitung sesuai tingkat kesulitannya.

Pembayarannya gimana?

DP 50% di awal, pelunasan sebelum file final dikirim. Bisa transfer bank, e-wallet, atau QRIS.

Harga website udah termasuk domain dan hosting?

Belum. Domain dan hosting dibayar terpisah, sekitar Rp 300–800rb per tahun. Kami bantu proses daftarnya.

Kalau batal di tengah jalan gimana?

Batal sebelum mulai dikerjakan, DP kami kembalikan penuh. Kalau sudah mulai dikerjakan, DP hangus. Detailnya ada di Syarat & Ketentuan.

Kenapa harganya murah?

Kami baru mulai, jadi pakai harga perkenalan buat ngumpulin klien pertama. Kualitas dan jumlah revisinya tetap sesuai paket.

Bisa order dari luar kota?

Bisa. Semua dikerjain online, brief dan file dikirim lewat WhatsApp atau email.

File apa aja yang aku dapet?

Desain dalam format PNG/JPG/PDF siap pakai. Logo paket Standard ke atas dapat file vektor. Bisa juga minta file Canva yang bisa diedit sendiri.
