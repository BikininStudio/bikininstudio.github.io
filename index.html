FAQ

Pertanyaan yang sering diajukan

Belum terjawab? Hubungi kami lewat WhatsApp atau email.

Apakah tersedia penawaran tertulis, invoice, dan kwitansi?

Ya. Penawaran harga tertulis dikirim sebelum pekerjaan dimulai, dan invoice serta kwitansi atas nama Bikinin Studio diterbitkan untuk setiap pembayaran.

Bisakah menandatangani perjanjian kerja atau NDA?

Bisa. Perjanjian kerja tertulis dan perjanjian kerahasiaan (NDA) dapat ditandatangani atas permintaan Anda. Proyek yang dirahasiakan tidak kami tampilkan di portofolio.

Apa bentuk usaha Bikinin Studio?

Bikinin Studio adalah studio desain independen berbentuk usaha perorangan, berbasis di Bekasi, dan melayani klien di seluruh Indonesia secara daring.

Berapa lama pengerjaannya?

Perkiraan waktu tercantum di setiap paket dan di penawaran. Sebagai gambaran: desain konten dan PPT tugas 1–3 hari, logo 3–7 hari, katalog 2–5 hari, website 1–4 minggu tergantung jumlah halaman. Layanan ekspres 1x24 jam tersedia dengan biaya tambahan 30%, menyesuaikan antrean.

Bagaimana sistem pembayarannya?

Umumnya DP 50% di awal dan pelunasan sebelum file final dikirim. Untuk proyek besar, pembayaran dapat dibagi beberapa termin sesuai penawaran. Pembayaran melalui transfer bank, e-wallet, atau QRIS.

Revisinya berapa kali?

Sesuai paket atau penawaran yang disepakati. Revisi tambahan untuk desain mulai Rp 10rb, untuk web dan aplikasi dihitung sesuai tingkat kesulitannya.

Siapa pemilik hak atas desainnya?

Setelah pelunasan, hasil desain sepenuhnya milik Anda. Font, foto, atau ikon pihak ketiga mengikuti lisensinya masing-masing dan akan kami informasikan bila ada yang berbayar.

Bagaimana jika proyek dibatalkan?

Jika dibatalkan sebelum pekerjaan dimulai, DP dikembalikan penuh. Jika sudah mulai dikerjakan, DP hangus. Detailnya ada di Syarat & Ketentuan.

Apakah harga website sudah termasuk domain dan hosting?

Belum. Domain dan hosting dibayar terpisah, sekitar Rp 300–800rb per tahun. Kami bantu proses pendaftarannya atas nama Anda.

File apa saja yang saya terima?

File siap pakai (PNG/JPG/PDF) dan, sesuai paket, file sumber seperti vektor logo, PPTX, atau file Canva yang bisa Anda sunting sendiri.

Mengapa paket UMKM harganya terjangkau?

Kami studio yang baru berjalan, sehingga memakai harga perkenalan untuk 10 klien pertama. Isi paket dan jumlah revisinya tidak dikurangi. Klien yang sudah sepakat tetap memakai harga lama.

Bisa melayani klien dari luar kota?

Bisa. Seluruh proses dilakukan secara daring: brief, pratinjau, dan file dikirim lewat WhatsApp atau email.
