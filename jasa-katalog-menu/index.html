Tahapan kerja

  1. 1

    Data produk

    Nama, harga, varian, dan foto produk. Format Excel, catatan, atau foto daftar harga dapat diterima.

  2. 2

    Penyusunan dan desain

    Produk dikelompokkan, diberi judul kategori, dan dilengkapi cara pemesanan di setiap halaman.

  3. 3

    File siap pakai

    PDF atau gambar untuk dibagikan, atau file siap cetak sesuai ukuran percetakan.

Pertanyaan seputar layanan ini

Apakah sekaligus dicetak?

File kami siapkan sesuai ukuran percetakan. Biaya cetak terpisah dan dapat dilakukan di percetakan pilihan Anda.

Harga sering berubah, bagaimana?

Mintalah file Canva agar Anda dapat memperbarui harga sendiri, atau pesan revisi kecil mulai Rp 10rb.

Apa bedanya dengan katalog WhatsApp Business?

Katalog WhatsApp Business berisi produk satu per satu di dalam aplikasi. Desain katalog dari kami dapat dipakai bersamaan: gambar produknya untuk katalog WhatsApp, file lengkapnya untuk dibagikan.

Berapa lama pengerjaannya?

Umumnya 2–5 hari, tergantung jumlah halaman dan kelengkapan data produk.

Pertanyaan umum mengenai pembayaran, dokumen, revisi, dan pembatalan tersedia di FAQ dan Syarat & Ketentuan.

Ceritakan proyek Anda

Konsultasi tanpa biaya dan tanpa kewajiban. Penawaran tertulis kami kirim sebelum pekerjaan dimulai.
